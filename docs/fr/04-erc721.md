# ERC-721 : un propriétaire par NFT

`ownerOf(tokenId)` identifie le propriétaire ; `balanceOf` compte ses NFT sans les énumérer.
`approve` autorise un NFT ; `setApprovalForAll` autorise un opérateur pour la collection.
`safeTransferFrom` vérifie qu'un destinataire contractuel accepte les NFT via le callback prévu.
**Exemple :** transférer le NFT 42 à Bob change son propriétaire, pas son identifiant. L'approbation spécifique est effacée.
**Piège :** `tokenURI` pointe vers des métadonnées. Leur permanence et les droits sur une image dépendent du projet.
